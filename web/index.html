Cách Nạp "Bộ Não" EduSkills-VN Vào Các Nền Tảng AI Phổ Biến

Bạn không cần lập trình phức tạp. Chỉ cần làm theo 3 bước cực kỳ đơn giản cho từng công cụ bạn đang dùng:

1. Google Gemini (Web / AI Studio)
  1. Mở Google AI Studio hoặc Gemini Web.
  2. Trong ô System Instructions, dán toàn bộ nội dung file SKILL.md bạn cần dùng.
  3. Đính kèm file PDF SGK từ thư mục sgk/ vào khung chat. Nhờ Context 2M tokens, Gemini sẽ hiểu trọn vẹn cuốn sách!
2. Anthropic Claude (Projects / Code)
  1. Tạo một Project mới trên Claude.ai đặt tên là "EduSkills-VN THPT".
  2. Tải các file SKILL.md từ thư mục skills/ vào mục Project Knowledge.
  3. Đặt System Prompt: "Bạn là Chuyên gia EduSkills-VN, luôn tuân thủ cấu trúc đề thi BGD 2026".
3. OpenAI ChatGPT (Custom GPTs)
  1. Vào Explore GPTs $\to$ Create a GPT.
  2. Trong tab Configure, dán nội dung file SKILL.md vào ô Instructions.
  3. Bật tính năng Code Interpreter để hỗ trợ vẽ đồ thị hàm số và tính toán số học chuẩn xác.
4. Google NotebookLM (Học Tập Đa Phương Tiện)
  1. Truy cập notebooklm.google.com và tạo Notebook mới.
  2. Tải các file SGK PDF trong thư mục sgk/ lên làm nguồn (Source).
  3. Nhấp nút Audio Overview để AI tự động biến cuốn SGK thành một buổi Podcast radio thảo luận bài học cực cuốn hút!
